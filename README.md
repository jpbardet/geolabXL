# geolabXL

Student page: https://jpbardet.github.io/geolabXL/

geolabXL is the Excel function library of the soil mechanics laboratory and of
*Experimental Soil Mechanics* (J.-P. Bardet, Prentice Hall, 1997). The functions are Excel
LAMBDA formulas stored inside each workbook; the page installs or updates them in a copy of
your workbook, in the browser.

This repository only serves the page (`docs/`, GitHub Pages). It is generated from the master
library in the geoXL repository (`tools/build.py`); do not edit `docs/` by hand.
